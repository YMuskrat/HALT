# Research sources and permitted reuse

Original HALT code is MIT. Stopping equations are independently implemented from
the pinned primary sources in `SOURCE_LEDGER.md`; no downloaded algorithm source
files or model/encoder weights are included in the wheel or source distribution.

HALT-CoT's author release and DEER's repository provide MIT notices. ThinkBrake's
audited repository does not supply its referenced generation implementation.
Answer Convergence did not have a verified root source license in the audited
snapshot; its code was read for algorithm auditing and was not copied. No verified
official REFRAIN source repository was established. License compatibility must be
rechecked before any future direct code port or wrapper redistributes source.

Installed optional dependencies and downloaded model assets retain their respective
licenses and notices in their own distributions/caches. HALT's package does not
claim ownership of the model names, checkpoint weights or original research methods.
