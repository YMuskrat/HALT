# Writing an external method

Run `halt new-method my_stopper --output examples/my_stopper`, then install the generated package using `python -m pip install -e examples/my_stopper`. The generated package declares a `halt.methods` packaging entry point. `halt methods list` discovers names and package versions without importing plugin modules; `halt methods inspect my_stopper` constructs the lightweight method and validates API version 1. IDs must use lowercase snake_case. A collision with a built-in or another plugin raises an error.

An author supplies a method class, `MethodSpec`, configuration, immutable source citation and focused decision fixtures. The three lifecycle methods are `reset(context)`, `observe(event)` and `decide()`. Use `BaseMethod` for a small implementation and keep constructor values as configuration. The runtime clones each configured method for each run. Reset every request-local counter in `reset`; never place active state on the class or in process globals. Repeated `decide()` calls without new observations must give the same decision.

Decisions are `Continue`, `RequestSignals`, `Finalize`, `ReturnAnswer` and `Abstain`. Probes bind an exact `PrefixRef` and `WorkLimit`; request them in a decision and wait for `ProbeCompleted`, `ProbeDenied` or `ProbeFailed`. The backend executes model work and the runtime accounts for it. Invalid probes are not agreement or high confidence. A returned answer must identify the validated probe that produced it. Gold labels remain entirely within `halt.evaluation` and must never be used by a method or adaptive session.

Existing typed computations are `ScoreCandidates`, `ProbeAnswer`, `ScoreNextToken`, `EmbedSteps`, and `ScoreAnswerSequence`. Their results distinguish candidate entropy, raw next-token features, parsed answers, embedding vectors, and token log likelihoods. Declare required capabilities and signal operations in `MethodSpec`, including the actual finalization recipe. If the source needs a new signal, first add a typed request/result and backend capability validation, then isolated accounting/probe tests. Keep neural clients, tensors and cache ownership in the backend or signal provider. Do not add a paper-name conditional to the generation loop.

Run `halt methods check my_stopper` for scripted lifecycle and state-isolation smoke checks, then the generated focused test with `python -m pytest examples/my_stopper/tests`. Passing this checker establishes API mechanics, not source fidelity or compatibility with real models. Add hand-checked fixtures covering the actual source equations and boundaries. Use replay only where the necessary observations and probe settings were recorded; missing counterfactuals deliberately raise `ReplayUnavailable`.

Existing upstream code can be wrapped when its license permits and its computation can be isolated from transport, inference loops, or ground-truth labels. Pin a commit, retain required notices, map each implemented step to the source, and distinguish direct reuse, independent reimplementation, common-protocol adaptation, and unresolved behavior. Do not claim author review until the author has actually reviewed the stated scope.

Evaluate a fixed recipe on declared development and calibration splits, freeze its parameters, and then use a disjoint held-out split. Save a complete cost ledger, backend/model revisions, parser, prompt identity and failures. Adaptive REFRAIN sessions use an explicit controller and ordered requests; no iid item bootstrap is applied to them. Credit research authors, implementers and reviewers for their actual roles.
